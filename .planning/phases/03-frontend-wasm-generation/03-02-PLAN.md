<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App-level request → generator adapter | Untrusted/malformed frontend inputs can reach a resource-intensive local runtime. |
| mlconfgen molecule output → normalized response | Runtime objects and geometry must be reduced to safe data without losing the authoritative MolBlock. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Denial of service | GenerateRequest validation | mitigate | Validate one reference form and finite positive sample/parameter values before invoking the runtime. |
| T-03-05 | Information disclosure | adapter errors | mitigate | Return sanitized failure categories/messages rather than low-level exception text. |
| T-03-06 | Tampering | geometry normalization | mitigate | Require non-empty `toMolBlock()` output and retain it on each GeneratedConformer; coordinates cannot replace it. |
| T-03-SC | Tampering | package runtime | mitigate | Continue using only packages approved in Plan 01's blocking legitimacy gate. |
</threat_model>
